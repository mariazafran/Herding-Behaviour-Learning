# Herding Behaviour in FTSE 100 (Learning & Pilot Study)

This repository documents my early-stage learning and experimentation 
in financial econometrics as part of my PhD journey.

## Overview
This project explores herding behaviour in UK equity markets using CSAD models.

## What this project includes
- Data collection using Python
- Stock return calculations
- CSAD (herding measure)
- Sector-level analysis
- Volatility modelling (GARCH)
- Regression analysis

## Purpose
This is a **learning and pilot study**, not a final research output.

The aim is to:
- Build understanding step by step
- Experiment with econometric models
- Develop financial data analysis skills

## Project Structure

- 01_learning_herding_analysis.ipynb → Initial CSAD model
- 02_sector_analysis.ipynb → Sector-level analysis and extensions

## Important Note
This repository includes:
- Initial attempts
- Errors and debugging
- Model improvements

This reflects the real research process.

## Tools Used
- Python (pandas, statsmodels, arch)
- yfinance
